🐍 Snake Game

Jednoduchá webová hra Snake vytvořená pomocí HTML, CSS a JavaScriptu.

Funkce

Pohyb hada pomocí šipek na klávesnici

Ovládání pomocí tlačítek na obrazovce

Sbírání jídla a zvyšování skóre

Detekce kolize a ukončení hry

Restart hry

Responzivní vzhled

Použité technologie

HTML5

CSS3

JavaScript

HTML Canvas

Spuštění projektu

Stáhni nebo naklonuj tento repozitář.

Otevři soubor index.html v prohlížeči.

Hru můžeš ovládat šipkami na klávesnici nebo tlačítky na obrazovce.
